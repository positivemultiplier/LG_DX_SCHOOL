Get방식

  1. URL에 데이터를 얹어서 전송
  2. 데이터의 길이의 제한 (1024byte)
  3. 데이터가 주소에 노출되기 때문에 보안에 취약
  4. form태그에 method 속성을 따로 작성하지 않으면 기본값
  5. post방식보다 빠르다 -> 캐시(임시저장소)를 활용하기 때문에 속도가 빠름!

Post방식

  1. 패킷의 body에 데이터를 담아서 전송
  2. 데이터 길이의 제한 X
  3. Get방식에 비해 보안이 강함
  4. form태그에 method 속성을 post로 작성해야함
  5. 데이터의 타입을 명시해야함 (Application/x-www-form-urlendcoded, multipart/form-data, text/plain)
