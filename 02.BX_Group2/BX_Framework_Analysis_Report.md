## 🎯 BX 특강 핵심 방법론 요약

### 1. Back Casting 방법론
- **ABCD Process**
  - A: Awareness & Defining Success (성공 정의)
  - B: Baseline Current State (현재 상태 파악)
  - C: Creative Solutions (창의적 솔루션)
  - D: Decide on Priorities (우선순위 결정)

### 2. Amazon Working Backward Process
- Customer (고객 중심)
- Press Release (언론 보도자료)
- FAQ (자주 묻는 질문)
- Visuals (시각적 자료)

### 3. Moon Shot Thinking
- 혁신적이고 도전적인 목표 설정
- "Shooting the Moon" 개념
- LG 6BX Case Scenario 적용

### 4. 문제 정의 프로세스 (Universe 식 접근)
- **Vertical Formulation**: Business Issue → Critical Issue → Data Issue
- **Horizontal Formulation**: Business Issue → Data Y factor → Y의 Business Valuation → X factor → Y=f(x) function
- V-Model Issue Formulation

### 5. BX 3대 아키텍처
- **Meaning Architecture**: 고객 경험/브랜드 의미 재정의
- **Value Creation Architecture**: 가치 창출 구조 혁신  
- **Operational Architecture**: 업무/조직 운영 혁신
