# 1 => LG 슬로건 공간의 확장을 보여주며
공간의 확장 => 공간 이 추상적인 단어를 깊이 생각해보았습니다. => 공간이 확장되기위해서는 이동이 필요합니다.=> 이동중에 비효율적인 부분은 없나? => 많은 분들의 집 한켠에는 여행중에 사용했던 Carrier들이 어딘가에 처박혀있을 것 입니다. => 혹은 반려동물을 키우시는 분들은 Pet Cage가 분명히 있을것입니다. 이 비효율성과 현재 반려동물을 키우고 있는 분들의 needs를 충족시키는 제품을 필요하다고 느꼈습니다. => 그래스 이 기획을 하게 되었습니다.  

# 2 => 뉴스 기사들을 띄우며 
여러분들도 이런 뉴스를 한번쯤 보셨을 것 입니다. 최근 반려동물과 여행을 떠나는 인구는 많이 늘어나고있습니다. 가벼운 차를 통한 이동은 쉽지만, 비행기는 동물보호법, 항공법 등의 법적 제약으로 인해 반려동물과 함께 여행을 떠난다는것은 쉽지 않은것이 현실입니다. => 미국의 한 사례처럼 반려견과 함께 탑승이 거부되자 반려동물을 살해하고 탑승을 시도하다 적발된 사례가도 있습니다. =>  탑승후에도 문제는 계속됩니다. 기내반입가능한 cage의 무게는 7kg~ 10kg으로 제한되므로, 나의 가족인 반려동물이 짐칸에 실려가야하는 상황이 발생합니다 => 또한 짐칸에 실려가는 반려동물은 더위에 결국 사망하는 사건도 발생합니다 외국에서는 이런 문제들을 dogs in cage? 라는 단어로 사회적 이슈가 되기도 합니다. => 우리나라도 최근 아시아나 항공에서 제주도까지 노선과정중 반려동물이 사망하는 사건이 발생하여 사회적인 이슈가 되었습니다. => 기내에 반입이 가능한 Cage에서도 문제는 있습니다. 발밑에 고정된 장소에서만 놓을 수 밖에 없습니다. 항공법에 의하여 cage에 손을 댈 수 없습니다. => 극심한 반려동물들의 스트레스를 동반하는 문제점이 발생하고, 그 상황을 체크할 수 없는 반려인들도 역시 스트레스를 받게됩니다. => 이러한 문제를 해결하기 위해서 LG는 반려동물과 함께 여행을 떠나는 사람들을 위한 제품을 기획하게 되었습니다.
