# AR 플러그인 빌드 에러 즉시 해결 가이드

## 🔴 현재 상황

pubspec.yaml에서 `ar_flutter_plugin: ^0.7.3`을 활성화했지만 빌드 시 다음 에러 발생:

```
Namespace not specified in ar_flutter_plugin build.gradle
```

---

## ✅ 해결 방법 (5분 안에 완료)

### 1단계: 패키지 다운로드
터미널에서 실행:
```cmd
cd C:\Users\lgdx\StudioProjects\ex02container
flutter pub get
```

### 2단계: AR 플러그인 build.gradle 수정

#### 파일 위치 찾기
1. `Win + R` 키 누르기
2. 다음 입력: `%LOCALAPPDATA%\Pub\Cache\hosted\pub.dev`
3. 폴더에서 `ar_flutter_plugin-0.7.3` 찾기
4. `android\build.gradle` 파일 열기

**전체 경로:**
```
C:\Users\lgdx\AppData\Local\Pub\Cache\hosted\pub.dev\ar_flutter_plugin-0.7.3\android\build.gradle
```

#### 파일 수정
**메모장으로 열기** (관리자 권한으로):
1. 메모장을 우클릭 → "관리자 권한으로 실행"
2. build.gradle 파일을 메모장으로 드래그

**수정할 내용:**

**수정 전 (약 22번째 줄):**
```gradle
android {
    compileSdkVersion 33

    defaultConfig {
        minSdkVersion 24
    }
```

**수정 후:**
```gradle
android {
    namespace 'io.carius.lars.ar_flutter_plugin'  // ⭐ 이 줄 추가!
    compileSdkVersion 33

    defaultConfig {
        minSdkVersion 24
    }
```

**저장** (Ctrl + S)

### 3단계: 클린 빌드
터미널에서 실행:
```cmd
flutter clean
flutter pub get
flutter run
```

## 💡 완전 자동화 PowerShell 스크립트

`fix_ar_namespace.ps1` 파일을 생성하고 다음 내용을 붙여넣기:

```powershell
# AR Plugin Namespace 자동 수정 스크립트
Write-Host "AR Flutter Plugin Namespace Fix" -ForegroundColor Cyan
Write-Host "=================================" -ForegroundColor Cyan

$pluginPath = "$env:LOCALAPPDATA\Pub\Cache\hosted\pub.dev"
$buildGradle = Get-ChildItem -Path $pluginPath -Filter "build.gradle" -Recurse -ErrorAction SilentlyContinue | 
    Where-Object { $_.FullName -like "*ar_flutter_plugin*android*" } | 
    Select-Object -First 1

if ($buildGradle) {
    Write-Host "`nFound: $($buildGradle.FullName)" -ForegroundColor Green
    
    # 백업
    $backupPath = "$($buildGradle.FullName).backup_$(Get-Date -Format 'yyyyMMdd_HHmmss')"
    Copy-Item $buildGradle.FullName $backupPath
    Write-Host "Backup created: $backupPath" -ForegroundColor Yellow
    
    # 내용 읽기
    $content = Get-Content $buildGradle.FullName -Raw
    
    # namespace 확인 및 추가
    if ($content -notmatch "namespace\s+['\`"]io\.carius\.lars\.ar_flutter_plugin['\`"]") {
        Write-Host "`nAdding namespace..." -ForegroundColor Yellow
        $newContent = $content -replace "(android\s*\{)", "`$1`n    namespace 'io.carius.lars.ar_flutter_plugin'"
        Set-Content $buildGradle.FullName $newContent -Encoding UTF8
        Write-Host "✅ Namespace added successfully!" -ForegroundColor Green
    } else {
        Write-Host "⚠️ Namespace already exists" -ForegroundColor Yellow
    }
    
    Write-Host "`n=================================" -ForegroundColor Cyan
    Write-Host "Next steps:" -ForegroundColor Cyan
    Write-Host "1. flutter clean" -ForegroundColor White
    Write-Host "2. flutter pub get" -ForegroundColor White
    Write-Host "3. flutter run" -ForegroundColor White
} else {
    Write-Host "`n❌ AR plugin build.gradle not found" -ForegroundColor Red
    Write-Host "Please run: flutter pub get" -ForegroundColor Yellow
}

Write-Host "`nPress any key to exit..."
$null = $Host.UI.RawUI.ReadKey("NoEcho,IncludeKeyDown")
```

**실행 방법:**
1. PowerShell을 관리자 권한으로 실행
2. 다음 명령 실행:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd C:\Users\lgdx\StudioProjects\ex02container
.\fix_ar_namespace.ps1
```
